# 🚀 About StudyBuddy

StudyBuddy is a full-stack productivity platform built to help students stay consistent with their studies.

Instead of simply recording study sessions, StudyBuddy provides meaningful insights through analytics, subject management, progress tracking, and a clean dashboard experience.

The long-term vision is to evolve StudyBuddy into a complete learning companion with AI-powered assistance, smart scheduling, reminders, and productivity tools.

# ⚙ Installation

## Clone

```bash
git clone https://github.com/chetanchauhan715/studybuddy.git
```

---

## Frontend

```bash
cd FrontEnd

npm install

npm run dev
```

---

## Backend

```bash
cd Backend

npm install

npm start
```
